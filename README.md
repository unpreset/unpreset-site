# UNPRESET site

Static landing page for **UNPRESET**.

## Brand source

Built to the UNPRESET Visual Brand Design Guide v3.2 using approved production SVG artwork from the UNPRESET Brand Assets package.

## Hosting

Designed for GitHub Pages with the custom domain `unpreset.com`.

## Files

- `index.html` — page structure, metadata, social links
- `styles.css` — responsive brand system and layout
- `assets/` — approved UNPRESET SVG production artwork
- `CNAME` — GitHub Pages custom-domain declaration
- `robots.txt` and `sitemap.xml` — basic search-engine discovery
